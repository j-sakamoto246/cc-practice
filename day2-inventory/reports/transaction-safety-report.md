# トランザクション安全性テスト結果

対象: 在庫移動 `stockTransfer` (倉庫A -> 倉庫B)

## 検証内容

| No. | 観点 | テスト | 結果 |
| --- | --- | --- | --- |
| 1 | 移動途中の意図的エラー | 移動先倉庫に存在しない ID を指定し、出庫後の入庫履歴作成で FK 制約エラーを発生させる | PASS |
| 2 | ロールバック後の在庫復元 | エラー後、移動元在庫が移動前数量に戻り、移動履歴も 0 件であることを検証 | PASS |
| 3 | 並行実行時の整合性 | 在庫 10 に対して 7 個の移動を 2 件同時実行し、1 件だけ成功、1 件失敗、総在庫 10 が保存されることを検証 | PASS |

## 実行コマンド

```bash
npm test -- tests/modules/stock-transaction-safety.test.ts
```

## 確認した不変条件

- 途中失敗した在庫移動では、移動元の減算が残らない。
- 途中失敗した在庫移動では、片側だけの `stock_movements` 履歴が残らない。
- 同時に 2 件の移動処理を実行しても、在庫不足になる処理は失敗し、成功した移動分だけが反映される。
- 並行実行後も、倉庫A・倉庫B・倉庫C の合計在庫は処理前と同じ 10 のまま保存される。
